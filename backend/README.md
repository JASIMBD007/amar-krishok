# AmarKrishok Backend

NestJS + Prisma backend for AmarKrishok.

## Setup

```bash
cd backend
cp .env.example .env
npm install
docker compose up -d
npm run prisma:generate
npm run prisma:migrate
npm run dev
```

API docs will be available at `http://localhost:4000/docs`.

## Render Free Deploy

The repository includes a `render.yaml` blueprint for the backend API.

Recommended free setup:

```txt
Backend API: Render Free Web Service
Database: Render Free Postgres for initial preview
Frontend: Netlify Free
```

Render Free Postgres expires after 30 days. For a longer free database, use Neon Free and replace `DATABASE_URL` in Render with the Neon pooled connection string.

Render service settings from the blueprint:

```txt
Root directory: backend
Build command: npm ci && npm run prisma:generate && npm run build
Pre-deploy command: npm run prisma:deploy
Start command: npm run start:prod
Health check path: /api/health
```

Render environment variables:

```txt
NODE_ENV=production
CORS_ORIGIN=https://www.amarkrishok.com,https://amarkrishok.com,https://amarkrishok.netlify.app,http://localhost:5173
JWT_SECRET=generated by Render
DATABASE_URL=provided by Render Postgres
```
