# AmarKrishok Mobile

Expo React Native app for AmarKrishok. It uses the same backend and database as the web app.

## Run locally

```bash
cd mobile
npm install
npm run start
```

Set `EXPO_PUBLIC_API_BASE_URL` when you need to point at a different backend:

```bash
EXPO_PUBLIC_API_BASE_URL=http://localhost:4000 npm run start
```
